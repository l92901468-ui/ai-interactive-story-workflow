从创作输入到可交付 Demo

每个页面对应一个清晰的用户任务和阶段产物；开放式 AI 生成被拆成可确认、可回溯、可复审的步骤。

00 · SYSTEM

UI 设计系统

统一导航、状态、颜色、组件与信息密度，为复杂创作工作台建立一致心智。

01 · COMMAND CENTER

项目总览与总控

集中呈现项目阶段、关键对象、风险与下一步，让创作链路不再黑箱。

02 · INGEST

素材导入与剧本提取

将文本、图片与备注转为可编辑对象，并保留来源与待确认项。

03 · ADAPTATION

改编策略与影游母体

先定义体验目标、主冲突与互动密度，再进入分支生成。

04 · WORLD MODEL

世界观文件与互动规则

把设定、约束和玩家可操作边界组织为可引用的结构化知识。

05 · CHARACTER STATE

角色阵营与信息差

围绕角色目标、关系、掌握信息和叙事筹码设计冲突。

06 · BRANCH GRAPH

主线合流与真实分歧

在可控成本下定义改变状态的分歧、回收点与结局路径。

07 · LOW-CODE LOGIC

变量与触发规则

用低代码心智表达条件、状态变化和跨章影响，降低逻辑维护成本。

08 · STORYLET

Storylet 卡片工作台

用可组合剧情块承载进入条件、演出内容与退出状态。

09 · CONSEQUENCE

剧情细化与选项后果

同时编辑玩家文案、即时反馈与长期后果，避免“伪选择”。

10 · SIMULATION

多人推演与并行行动

围绕角色视角、并行行动和信息差检查叙事一致性。

11 · QUALITY GATE

审校修补与逻辑质控

集中暴露断链、变量冲突、角色越界和未回收伏笔，并给出修补入口。

12 · PLAYTEST

试玩预览与分支回放

在交付前按路线回放选择与状态变化，让体验验收有据可查。

13 · DELIVERY

导出交付与团队协作

把版本、格式、责任人与交付状态放进同一视图，闭合制作链路。
